Глава 21: Биоинформатика и геномика

1. Секвенсирование ДНК

Методы секвенсирования

Секвенсирование — определение нуклеотидной последовательности ДНК. Современные методы делятся на три поколения:

1-е поколение: Sanger

Классический метод终止子ного секвенсирования. Использует дидеоксинуклеотиды (ddNTPs) для обрыва цепи. Точность $>99.99\%$, но низкая пропускная способность ($\sim 900$ нуклеотидов за чтение).

$$\text{Длина чтения} \sim 900\text{ bp}, \quad \text{Стоимость} \sim \$0.001/\text{bp}$$

2-е поколение: NGS

Параллельное секвенсирование (Illumina, Ion Torrent). Считывает миллионы фрагментов одновременно. Высокая пропускная способность, но короткие чтения ($150-300$ bp).

$$\text{Пропускная способность} \sim 10^9\text{ reads/run}, \quad \text{Стоимость} \sim \$0.000001/\text{bp}$$

3-е поколение: Long-read

PacBio (SMRT) и Nanopore (Oxford). Длинные чтения ($10-100$ kbp), но выше ошибки ($\sim 10\%$ для Nanopore). Позволяют определять метилирование и структурные вариации.

$$\text{Длина чтения} \sim 10-100\text{ kbp}, \quad \text{Ошибка} \sim 10^{-1}$$

Математика секвенсирования

Покрытие генома определяется формулой:

$$C = \frac{N \cdot L}{G}$$

где $C$ — покрытие, $N$ — количество чтений, $L$ — длина чтения, $G$ — размер генома. Для надёжной сборки требуется $C \geq 30$.

2. Alignment и assembly

Выравнивание последовательностей

Alignment — поиск оптимального выравнивания двух последовательностей для определения гомологии.

BLAST (Basic Local Alignment Search Tool)

Эвристический алгоритм для быстрого поиска сходства. Состоит из трёх этапов:

  1. Создание таблицы слов (word list) из запроса
  2. Расширение точных совпадений (seeding)
  3. Оценка статистической значимости ($E$-value)

$E$-value = $K \cdot m \cdot n \cdot e^{-\lambda S}$, где $m, n$ — длины последовательностей, $S$ — Score.

Needleman-Wunsch (глобальное выравнивание)

Динамическое программирование для глобального выравнивания. Рекуррентное соотношение:

$$F(i,j) = \max\begin{cases} F(i-1,j-1) + s(x_i, y_j) \\ F(i-1,j) + \delta \\ F(i,j-1) + \delta \end{cases}$$

где $s(x_i, y_j)$ — матрица подстановки, $\delta$ — штраф за разрыв (gap penalty). Сложность: $\BigO(mn)$.

Smith-Waterman (локальное выравнивание)

Аналог Needleman-Wunsch, но с обнулением отрицательных значений для поиска локальных регионов сходства:

$$F(i,j) = \max\begin{cases} 0 \\ F(i-1,j-1) + s(x_i, y_j) \\ F(i-1,j) + \delta \\ F(i,j-1) + \delta \end{cases}$$

Сборка генома (Assembly)

Восстановление полной последовательности генома из коротких чтений. Два основных подхода:

  • De novo assembly — без референсного генома (de Bruijn графы, overlap graphs)
  • Reference-based assembly — выравнивание на референс (BWA, Bowtie)

Сложность de novo assembly: $\BigO(N \log N)$ для de Bruijn графа с $N$ Reads.

3. Филогенетика

Построение деревьев эволюции

Филогенетика — реконструкция эволюционных взаимоотношений между организмами на основе молекулярных данных.

Distance-based methods

Neighbor-Joining: Агломеративный метод, минимизирующий общую длину дерева. Использует матрицу попарных дистанций $d_{ij}$.

$$\text{Цель: } \min \sum_{i<j} d_{ij} \cdot \ell_{ij}$$

Maximum Parsimony

Минимизирует количество мутаций (различий) вдоль ветвей дерева. Ищет дерево с минимальным Score.

$$\text{Score}(T) = \sum_{\text{vertices}} \text{parsimony steps}$$

Maximum Likelihood

Находит дерево $T$, максимизирующее правдоподобие данных при заданной эволюционной модели $M$:

$$\hat{T} = \arg\max_T P(\text{Data} \mid T, M)$$

Bayesian Inference

Вычисляет апостериорное распределение деревьев:

$$P(T \mid \text{Data}) \propto P(\text{Data} \mid T) \cdot P(T)$$

Молекулярные часы

Гипотеза о постоянстве эволюционных изменений во времени. Скорость замен $\mu$:

$$d = 2\mu t$$

где $d$ — генетическое расстояние, $t$ — время дивергенции. Для нейтральных замен $\mu \approx 10^{-9}$ замен/нуклеотид/год.

4. Структура белков

Предсказание трёхмерной структуры

Проблема фолдинга: предсказание 3D-структуры белка по аминокислотной последовательности. Одна из ключевых задач биоинформатики.

AlphaFold (DeepMind)

Нейросеть, использующая attention-механизмы для предсказания межостатковых расстояний. Точность $>90\%$ (GDT-TS score).

  • Вход: аминокислотная последовательность + MSA (multiple sequence alignment)
  • Выход: координаты C$\alpha$ атомов + confidence scores (pLDDT)
$$\text{pLDDT} = \frac{1}{N} \sum_{i=1}^N \text{LDDT}_i$$

Свободная энергия фолдинга

Термодинамическая стабильность белка определяется изменением свободной энергии Гиббса:

$$\Delta G_{\text{fold}} = \Delta H - T \Delta S$$

Где $\Delta H$ — энтальпия (водородные связи, ван-дер-ваальсовы силы), $T$ — температура, $\Delta S$ — энтропия (конформационная энтропия, гидрофобный эффект).

Стабильные белки имеют $\Delta G_{\text{fold}} \approx -20$ до $-60$ кДж/моль.

5. Связь с химией и физикой

Ферменты и метаболизм

Ферменты — белки-катализаторы, ускоряющие биохимические реакции. Кинетика Михаэлиса-Ментен:

$$v = \frac{V_{\max} [S]}{K_m + [S]}$$

где $v$ — скорость реакции, $V_{\max}$ — максимальная скорость, $[S]$ — концентрация субстрата, $K_m$ — константа Михаэлиса.

Метаболические пути — сети ферментативных реакций. Анализ потока (flux balance analysis):

$$\mathbf{S} \cdot \mathbf{v} = 0$$

где $\mathbf{S}$ — стехиометрическая матрица, $\mathbf{v}$ — вектор скоростей реакций.

Термодинамика белков

Взаимодействия белков с лиандами описываются константами диссоциации:

$$K_d = \frac{[P][L]}{[PL]} = e^{\Delta G^\circ / RT}$$

где $\Delta G^\circ$ — стандартная энергия Гиббса, $R = 8.314$ Дж/(моль·К), $T$ — температура.

Гидрофобный эффект — основная движущая сила фолдинга:

$$\Delta G_{\text{hydro}} = \Delta H_{\text{hydro}} - T \Delta S_{\text{hydro}}$$

При $T = 310$ К (37°C) $\Delta G_{\text{hydro}} \approx -25$ Дж/моль на гидрофобный атом.

6. Связь с задачами тысячелетия

Задача Бёрча и Свиннертон-Дайера (BSD) — одна из задач тысячелетия, связанная с эллиптическими кривыми над $\Q$:

$$E: y^2 = x^3 + ax + b, \quad a, b \in \Q$$

Гипотеза BSD утверждает, что ранг $r$ группы рациональных точек $E(\Q)$ равен порядку нуля $L(E, s)$ в $s = 1$.

Эллиптические кривые в криптографии ДНК

ДНК-криптография использует свойства ДНК для шифрования данных. Сочетание с эллиптическими кривыми даёт гибридную систему:

  • Кодирование: Преобразование ДНК в точки эллиптической кривой: $A \to (x_1, y_1)$, $T \to (x_2, y_2)$, $G \to (x_3, y_3)$, $C \to (x_4, y_4)$
  • Шифрование: Умножение точки на скаляр (ECC): $Q = k \cdot P$, где $k$ — секретный ключ
  • Стойкость: Проблема дискретного логарифмирования на эллиптических кривых (ECDLP)
$$\text{Безопасность} \sim 2^{128} \text{ операций (при } n = 256\text{ бит)}$$

Связь с геномикой: Хранение данных в синтетической ДНК требует эффективного кодирования и纠错. Коды Рида-Соломона, используемые в ECC, применяются и для纠错 ДНК-данных.

7. Оптимизация для LLM

Структура данных для обучения

Каждый факт биоинформатики формализуется как:

  • Определение: Термин + контекст
  • Формула: Математическая запись с объяснением переменных
  • Пример: Конкретный случай (organism, gene, mutation)
  • Связи: Ссылки на другие главы (химия, физика, информатика)

Параллельная генерация

# Паттерн генерации биоинформатических фактов
for topic in ['sequencing', 'alignment', 'phylogenetics', 'proteomics']:
    for subtopic in topic.subtopics:
        fact = generate_fact(subtopic)
        verify(fact)  # проверка биологической корректности
        if passed: save(fact)
        else: refine(fact) → retry(up_to=3)

Метрики качества

$$\text{Accuracy} = \frac{\text{биологически корректных утверждений}}{\text{всего утверждений}} \times 100\%$$

Целевой показатель: $>95\%$ точности для учебных материалов.
