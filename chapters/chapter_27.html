Глава 27: Информатика — от алгоритмов к искусственному интеллекту

Информатика — это наука о вычислениях, обработке информации и автоматизации. В рамках серии «1001 Proof» том по информатике охватывает 1001 формальное доказательство и теорему: от базовых алгоритмов и структур данных до теории вычислений, криптографии и искусственного интеллекта.

$$\text{Информатика} = \text{Алгоритмы} + \text{Структуры данных} + \text{Вычисления} + \text{ИИ} + \text{Криптография}$$

1. Алгоритмы — сортировки, поиски, графовые алгоритмы, сложность O()

Определение алгоритма

Алгоритм — это конечная последовательность чётких инструкций для решения определённого класса задач. Каждый алгоритм обладает свойствами: дискретностью, определённостью, конечностью и наличием входных/выходных данных.

1.1 Сортировки

Сортировка — фундаментальная задача: упорядочить $n$ элементов.

АлгоритмХудший случайСреднийПамять
Пузырьком$\BigO(n^2)$$\BigO(n^2)$$\BigO(1)$
Выбором$\BigO(n^2)$$\BigO(n^2)$$\BigO(1)$
Вставками$\BigO(n^2)$$\BigO(n^2)$$\BigO(1)$
Слиянием$\BigO(n \log n)$$\BigO(n \log n)$$\BigO(n)$
Быстрая (QuickSort)$\BigO(n^2)$$\BigO(n \log n)$$\BigO(\log n)$
Кучей (HeapSort)$\BigO(n \log n)$$\BigO(n \log n)$$\BigO(1)$
Подсчётом$\BigO(n + k)$$\BigO(n + k)$$\BigO(k)$
$$T_{\text{merge}}(n) = 2T\left(\frac{n}{2}\right) + \BigO(n) \implies T(n) = \BigO(n \log n)$$

Нижняя граница: любая сортировка сравнениями требует $\Omega(n \log n)$ операций (доказывается через дерево решений).

1.2 Поиски

Линейный поиск: $\BigO(n)$ — перебор всех элементов.

Бинарный поиск: $\BigO(\log n)$ — на отсортированном массиве:

$$\text{left} \leq \text{mid} \leq \text{right} \implies \text{область поиска уменьшается вдвое}$$

Интерполяционный поиск: $\BigO(\log \log n)$ для равномерно распределённых данных.

1.3 Графовые алгоритмы

Обход в ширину (BFS): $\BigO(V + E)$ — поиск кратчайшего пути в невзвешенном графе.

Обход в глубину (DFS): $\BigO(V + E)$ — обнаружение циклов, топологическая сортировка.

Дейкстра: $\BigO((V + E) \log V)$ — кратчайший путь с неотрицательными весами:

$$d[v] = \min(d[v], d[u] + w(u, v))$$

Беллмана-Форд: $\BigO(VE)$ — отрицательные рёбра, обнаружение отрицательных циклов.

Флойд-Уоршелл: $\BigO(V^3)$ — все пары кратчайших путей.

1.4 Асимптотический анализ

О-большое (Big-O):

$$f(n) = \BigO(g(n)) \iff \exists\, c > 0,\, n_0 : \forall n > n_0,\, f(n) \leq c \cdot g(n)$$

Омега (Big-Omega):

$$f(n) = \Omega(g(n)) \iff \exists\, c > 0,\, n_0 : \forall n > n_0,\, f(n) \geq c \cdot g(n)$$

Тета (Big-Theta):

$$f(n) = \Theta(g(n)) \iff f(n) = \BigO(g(n)) \land f(n) = \Omega(g(n))$$

Иерархия сложностей:

$$\BigO(1) \subset \BigO(\log n) \subset \BigO(\sqrt{n}) \subset \BigO(n) \subset \BigO(n \log n) \subset \BigO(n^2) \subset \BigO(n^3) \subset \BigO(2^n) \subset \BigO(n!)$$

2. Структуры данных — деревья, хэш-таблицы, кучи, графы

Принцип выбора

Выбор структуры данных определяет эффективность алгоритма. Тот же алгоритм может быть $\BigO(n)$ или $\BigO(n \log n)$ в зависимости от底层 структуры.

2.1 Деревья

Двоичное дерево поиска (BST): операции в среднем $\BigO(\log n)$, в худшем — $\BigO(n)$.

Сбалансированные деревья:

  • AVL: строгое балансировка, высота $\leq 1.44 \log_2 n$
  • Красно-чёрные: гарантия $\BigO(\log n)$ для всех операций
  • B-деревья: оптимальны для дисковых носителей, используются в БД
  • Деревья префиксов (Trie): хранение строк, поиск по префиксу $\BigO(m)$, $m$ — длина строки

2.2 Хэш-таблицы

Средняя сложность: $\BigO(1)$ для вставки, поиска, удаления.

Хэш-функция:

$$h(k) = k \mod m \quad \text{(простая)}$$
$$h(k) = \lfloor m \cdot ((k \cdot A) \mod 1) \rfloor \quad \text{(мультипликативная, } A = \frac{\sqrt{5}-1}{2}\text{)}$$

Коллизии: метод цепочек $\BigO(1 + \alpha)$, метод открытой адресации $\BigO\!\left(\frac{1}{1-\alpha}\right)$, где $\alpha = n/m$ — коэффициент заполнения.

Бэджи-хэширование: вероятностная техника для обнаружения несанкционированных изменений.

2.3 Кучи (Heaps)

Двоичная куча: дерево, где $parent(i) \geq child(i)$ для max-кучи.

  • Insert: $\BigO(\log n)$ — «всплытие» (bubble-up)
  • Extract-Min/Max: $\BigO(\log n)$ — «погружение» (heapify-down)
  • Build-Heap: $\BigO(n)$ — фертильная построение

Binomial heap: $\BigO(\log n)$ для merge.

Fibonacci heap: $\BigO(1)$ amortized для insert, $\BigO(\log n)$ для extract.

2.4 Графы

Матрица смежности: $\BigO(V^2)$ памяти, $\BigO(1)$ для проверки ребра.

Список смежности: $\BigO(V + E)$ памяти, оптимальна для разреженных графов.

Матрица инциденций: используется для бипартитных графов.

$$\text{Степень вершины:} \quad \deg(v) = \sum_{u \in V} A[v][u] \quad (\text{матрица смежности})$$

Формула рукопожатий:

$$\sum_{v \in V} \deg(v) = 2|E|$$

3. Теория вычислений — автоматы, разрешимость, NP-полнота

Теория вычислений изучает фундаментальные ограничения того, что может быть вычислено.

3.1 Модели вычислений

Машина Тьюринга: формальная модель вычислений. Доказано, что any algorithmic computation может быть смоделирован на машине Тьюринга.

$$M = (Q, \Sigma, \Gamma, \delta, q_0, q_{accept}, q_{reject})$$

Иерархия Хомского:

  • Type 0: рекурсивно перечисляемые языки (машина Тьюринга)
  • Type 1: контекстно-свободные (автомат с магазинной памятью)
  • Type 2: регулярные (конечный автомат)
  • Type 3: regular expressions
$$\text{Type 3} \subsetneq \text{Type 2} \subsetneq \text{Type 1} \subsetneq \text{Type 0}$$

3.2 Разрешимость

Разрешимая задача: существует алгоритм, который всегда завершается с ответом «да» или «нет».

Неразрешимая задача: остановка (halting problem) — невозможно определить, завершится ли произвольная программа.

$$\text{HALT} = \{(M, w) : M \text{ останавливается на } w\} \quad \text{— неразрешим}$$

Тезис Чёрча-Тьюринга: любая «эффективно вычислимая» функция вычислима на машине Тьюринга.

3.3 Классы сложности

P: задачи, решаемые за время polynomial:

$$P = \bigcup_{k \geq 1} \text{DTIME}(n^k)$$

NP: задачи, для которых вердикт «да» верифицируется за polynomial время:

$$\text{NP} = \bigcup_{k \geq 1} \text{NTIME}(n^k)$$

NP-полные задачи: любая задача из NP poly-reduцируется к ним:

$$A \leq_p B \iff \exists \text{ poly-time reduce } f : x \in A \iff f(x) \in B$$

Примеры NP-полных: 3-SAT, задача коммивояжёра, задача о рюкзаке, раскраска графов, клика.

NP-трудные: не менее сложные, чем NP-полные (но не обязательно в NP). Пример: остановка машины Тьюринга.

PSPACE: задачи, решаемые с polynomial объёмом памяти. $P \subseteq NP \subseteq PSPACE$.

4. Искусственный интеллект — обучение с учителем/без, нейросети, reinforcement learning

Краткая история ИИ

1950: Тьюринг-тест. 1956: конференция в Дартмуте (рождение ИИ). 1997: Deep Blue побеждает Каспарова. 2012: AlexNet — начало deep learning. 2017: архитектура Transformer. 2020: GPT-3. 2023: GPT-4, multimodal модели.

4.1 Обучение с учителем (Supervised Learning)

На вход подаются пары $(x_i, y_i)$ — данные и правильные ответы. Цель: найти $f: X \to Y$, минимизируя функцию потерь.

$$\mathcal{L}(\theta) = \frac{1}{n} \sum_{i=1}^{n} \ell(f_\theta(x_i), y_i)$$

Градиентный спуск:

$$\theta_{t+1} = \theta_t - \alpha \nabla_\theta \mathcal{L}(\theta_t)$$

Метрики:

  • Классификация: accuracy, precision, recall, F1-score, AUC-ROC
  • Регрессия: MSE, MAE, $R^2$
$$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN} \qquad \text{F1} = 2 \cdot \frac{P \cdot R}{P + R}$$

4.2 Обучение без учителя (Unsupervised Learning)

Данные без меток. Задачи: кластеризация, снижение размерности, генерация.

K-means:

$$\min_{C_1,\ldots,C_k} \sum_{i=1}^{k} \sum_{x \in C_i} \|x - \mu_i\|^2$$

PCA: поиск главных компонент, максимизация дисперсии:

$$w^* = \arg\max_w \frac{w^T \Sigma w}{w^T w}$$

Autoencoders: обучение компактного представления через сжатие-восстановление.

4.3 Нейросети (Deep Learning)

Нейрон:

$$y = \sigma\!\left(\sum_{i=1}^{n} w_i x_i + b\right) = \sigma(w^T x + b)$$

Функции активации:

  • Sigmoid: $\sigma(z) = \frac{1}{1+e^{-z}}$
  • ReLU: $f(z) = \max(0, z)$
  • Tanh: $\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$
  • Softmax: $\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}$

Свёрточные сети (CNN): извлекают пространственные признаки. Свёртка:

$$(f * g)(t) = \int f(\tau) g(t - \tau) d\tau \quad \text{или в дискретном случае} \quad (f * g)[n] = \sum_{k} f[k] g[n-k]$$

Рекуррентные сети (RNN): обрабатывают последовательности. LSTM — забывают/запоминают через «ворота»:

$$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) \quad \text{(forget gate)}$$

Transformer: self-attention mechanism — основа GPT, BERT:

$$\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right) V$$

Масштабирование:

  • LeNet-5 (1998): 60K параметров
  • AlexNet (2012): 60M параметров
  • GPT-3 (2020): 175B параметров
  • GPT-4 (2023): ~1.8T параметров (MoE)

4.4 Reinforcement Learning (обучение с подкреплением)

Агент взаимодействует со средой: действие $a_t$ → состояние $s_{t+1}$ + награда $r_t$.

Функция ценности (value function):

$$V^\pi(s) = \mathbb{E}_\pi\!\left[\sum_{t=0}^{\infty} \gamma^t r_t \mid s_0 = s\right]$$

Уравнение Беллмана:

$$V^*(s) = \max_a \sum_{s'} P(s'|s,a)\left[R(s,a,s') + \gamma V^*(s')\right]$$

Q-learning:

$$Q(s,a) \leftarrow Q(s,a) + \alpha\!\left[r + \gamma \max_{a'} Q(s',a') - Q(s,a)\right]$$

Deep Q-Network (DQN): нейросеть приближает $Q(s,a)$.

Policy Gradient (REINFORCE):

$$\nabla_\theta J(\theta) = \mathbb{E}_\pi\!\left[\nabla_\theta \log \pi_\theta(a|s) \cdot G_t\right]$$

Примеры: AlphaGo (2016), OpenAI Five (2019), ChatGPT (RLHF — reinforcement learning from human feedback).

5. Криптография — симметричное/ассиметричное шифрование, хэш-функции

Криптография обеспечивает конфиденциальность, целостность и аутентификацию данных. Фундаментально опирается на математику: теорию чисел, алгебру, теорию вероятностей.

5.1 Симметричное шифрование

Один ключ для шифрования и дешифрования: $E(k, m) = c$, $D(k, c) = m$.

AES (Advanced Encryption Standard):

  • Блок: 128 бит, ключ: 128/192/256 бит
  • 10/12/14 раундов (зависит от ключа)
  • Operations: SubBytes, ShiftRows, MixColumns, AddRoundKey

Безопасность: при $n$-битном ключе brute-force требует $\BigO(2^n)$ операций.

$$\text{Безопасность AES-256:} \quad 2^{256} \approx 10^{77} \text{ операций}$$

5.2 Асимметричное шифрование (Public Key)

Два ключа: публичный $(e, n)$ для шифрования, приватный $(d, n)$ для расшифрования.

RSA:

  • Генерация: два простых $p, q$, $n = pq$, $\phi(n) = (p-1)(q-1)$
  • Шифрование: $c = m^e \mod n$
  • Расшифрование: $m = c^d \mod n$
  • Связь: $ed \equiv 1 \pmod{\phi(n)}$
$$ed \equiv 1 \pmod{(p-1)(q-1)} \quad \text{(extended Euclidean algorithm)}$$

ECC (Elliptic Curve Cryptography): аналогичная безопасность с меньшим ключом (256 бит ECC ≈ 3072 бит RSA).

$$y^2 = x^3 + ax + b \pmod{p} \quad \text{(эллиптическая кривая)}$$

5.3 Хэш-функции

$H: \{0,1\}^* \to \{0,1\}^n$ — детерминированная функция фиксированной длины вывода.

Свойства:

  • Pre-image resistance: по $y$ сложно найти $x$ : $H(x) = y$
  • Second pre-image resistance: по $x_1$ сложно найти $x_2 \neq x_1$ : $H(x_1) = H(x_2)$
  • Collision resistance: сложно найти любые $x_1 \neq x_2$ : $H(x_1) = H(x_2)$

Атака дней рождения:

$$\text{Вероятность коллизии} \approx 1 - e^{-k^2 / 2^{n+1}}$$

Для 256-битного хэша: $\approx 2^{128}$ операций.

SHA-256: 256-бит вывод, 64 раунда. SHA-3 (Keccak): sponge-конструкция.

6. Связь с математикой (комбинаторика, логика) и физикой (квантовые вычисления)

6.1 Комбинаторика

Биномиальные коэффициенты:

$$\binom{n}{k} = \frac{n!}{k!(n-k)!} \quad \text{— число подмножеств размера } k$$

Принцип включений-исключений:

$$|A_1 \cup A_2 \cup \ldots \cup A_n| = \sum_{i} |A_i| - \sum_{i

Связь с информатикой:

  • Анализ алгоритмов: число вариантов, сложность перебора
  • Криптография: вычислительная сложность взлома
  • Кодирование: число возможных кодов, вероятность ошибки

6.2 Математическая логика

Булева алгебра: фундамент цифровых схем и алгоритмов.

$$\text{AND: } a \land b, \quad \text{OR: } a \lor b, \quad \text{NOT: } \neg a, \quad \text{XOR: } a \oplus b$$

Предикатная логика: основа формальных систем и программной верификации.

$$\forall x \in X, \exists y \in Y : P(x, y) \quad \text{(формула первого порядка)}$$

Теорема Гёделя о неполноте: в любой непротиворечивой формальной системе, содержащей арифметику, существуют истинные, но недоказуемые утверждения.

6.3 Квантовые вычисления

Кубит:

$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle, \quad |\alpha|^2 + |\beta|^2 = 1$$

Квантовые вентили:

  • Hadamard: $H = \frac{1}{\sqrt{2}}\begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}$
  • CNOT: контролируемое-NOT
  • Toffoli: контролируемое-управляемое-NOT

Алгоритм Шора: факторизация за $\BigO((\log n)^3)$ — ломает RSA.

$$\text{Классический: } \BigO(e^{n^{1/3}}) \quad \text{vs} \quad \text{Квантовый: } \BigO((\log n)^3)$$

Алгоритм Гровера: поиск в неупорядоченной БД за $\BigO(\sqrt{N})$ вместо $\BigO(N)$.

$$|+\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle) \quad \text{(суперпозиция)}$$

7. Связь с задачами тысячелетия (P vs NP, квантовые алгоритмы)

Задача P vs NP

Главная нерешённая проблема информатики:

$$\boxed{P \stackrel{?}{=} NP}$$

Если $P = NP$, то любая задача, верифицируемая за polynomial время, может быть и решена за polynomial время. Это имело бы катастрофические последствия для криптографии.

Если P = NP: RSA, ECC, AES — все современные криптосистемы сломаны.

Если P ≠ NP: существуют задачи, которые принципиально проще верифицировать, чем решать.

7.1 Влияние на криптографию

Современная криптография основана на предположении $P \neq NP$:

  • RSA:困難ность факторизации (не доказано NP-полным, но poly-time алгоритм неизвестен)
  • ECC:困难ность дискретного логарифмирования на эллиптических кривых
  • Асимметричное:困难ность решений certain lattice problems (LWE)

Постквантовая криптография: алгоритмы, устойчивые к квантовым атакам:

  • Lattice-based: CRYSTALS-Kyber, CRYSTALS-Dilithium (NIST标准)
  • Code-based: Classic McEliece
  • Hash-based: SPHINCS+

7.2 Квантовые алгоритмы и задачи тысячелетия

Алгоритм Шора для факторизации:

$$\text{Классический:} \quad \BigO(e^{(\log N)^{1/3} (\log \log N)^{2/3}}) \quad \text{(GNFS)}$$
$$\text{Квантовый:} \quad \BigO((\log N)^3) \quad \text{(Shor's algorithm)}$$

Квантовое supremacy: Google (2019) — 53 кубита, задача random circuit sampling за 200 секунд vs классический суперкомпьютер ~10,000 лет.

Квантовое преимущество для оптимизации: Variational Quantum Eigensolver (VQE) — поиск ground state для химических молекул.

$$H|\psi\rangle = E|\psi\rangle \quad \text{(Shrödinger equation — quantum chemistry)}$$

7.3 Связь с другими задачами тысячелетия

P vs NP и Навье-Стокс: существование и гладкость решений уравнений Навье-Стокса — это задача, которая может быть связана с вычислительной сложностью.

P vs NP и теория Хорна: доказательство или опровержение $P = NP$ потребует глубоких результатов в области теории вычислений.

Квантовые компьютеры и задачи тысячелетия:

  • Риман гипотеза: квантовые вычисления для проверки нулей
  • Решение уравнений Навье-Стокса: квантовые методы для турбулентности
  • Гипотеза Ходжа: формальная верификация через компьютерную алгебру

Оптимизация: от теории к практике

Ускорение x10: Параллелизация: GPU для нейросетей, распараллеливание графовых алгоритмов.

Ускорение x100: Квантовые алгоритмы для специфических задач: Шор (факторизация), Гровер (поиск).

Ускорение x1000: Нейроморфные чипы и специализированные TPU для deep learning.
