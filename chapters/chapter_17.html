Глава 17: Разбор решений

Оглавление

Детальный разбор ключевых задач из главы 16: полные решения 6 задач тысячелетия (в той мере, в которой они решены частично), междисциплинарные связи и методологические выводы.

1. Задачи тысячелетия — полные разборы

Задача 1: BSD — частный случай $L(E,1) \neq 0$

Утверждение: Если $L(E,1) \neq 0$, то $E(\mathbb{Q})$ — конечная группа (ранг = 0).

Доказательство ( sketch):

1. Формула Бёрча–Тейтена связывает $L(E,1)$ с $\#\text{Ш}(E)$ и регулятором $R$:

$$\frac{L(E,1)}{\Omega_E \cdot R_E} = \frac{\#\text{Ш}(E) \cdot \prod c_p}{\#E(\text{tors})^2}$$

2. Если $L(E,1) \neq 0$, правая часть конечна → $\text{Ш}(E)$ конечна и $R_E$ определён.

3. Конечный регулятор + конечная Шафаревича–Тейтена → конечный ранг.

Статус: Доказано (Гросс–Загирер, 1986; Коин–Ленстра, 1984).

Задача 3: Римана — формула подсчёта

Утверждение: Если все нетривиальные нули $\zeta(s)$ на $\mathrm{Re}(s) = 1/2$, то $|\pi(x) - \mathrm{li}(x)| = O(\sqrt{x}\ln x)$.

Доказательство (sketch):

1. Формула подсчёта простых:

$$\pi(x) = \mathrm{li}(x) - \sum_{\rho} \mathrm{li}(x^\rho) + O(1)$$

где сумма по нетривиальным нулям $\rho = \beta + i\gamma$.

2. Если $\beta = 1/2$ для всех $\rho$: $|x^\rho| = x^{1/2}$, поэтому $|\mathrm{li}(x^\rho)| \leq C \cdot x^{1/2} / |\gamma|$.

3. Суммирование сходится (густота нулей $\sim \frac{1}{2\pi}\ln|t|$): ошибка $= O(\sqrt{x} \ln x)$.

Статус: Один из эквивалентов гипотезы Римана. НЕ доказано.

Задача 4: Навье–Стокс в 2D

Утверждение: Для $u_0 \in L^2(\mathbb{R}^2)$ существует единственное гладкое решение на всём времени.

Доказательство (Ladyzhenskaya, 1959):

1. Уравнение энергии (inner product с $u$):

$$\frac{1}{2}\frac{d}{dt}\|u\|_{L^2}^2 + \nu\|\nabla u\|_{L^2}^2 = 0$$

2. Неравенство Гронвалла: $\|u(t)\|_{L^2} \leq \|u_0\|_{L^2}$ для всех $t$.

3. В 2D: $\|u\|_{L^4} \leq C \|u\|_{L^2}^{1/2} \|\nabla u\|_{L^2}^{1/2}$ (interpolation) → контролируемая энергия.

4. Гладкость следует из parabolic regularity.

Задача 9: Критерий Серы

Утверждение: Если $\int_0^T \|u(\cdot,t)\|_{L^3}^3 dt < \infty$, то решение гладкое на $[0,T)$.

Доказательство (sketch):

1. $L^3$ — критическая гомогенная норма для Навье–Стокса в 3D (размерность $[L^3] = L^{-1}$, как и у вязкого члена).

2. Через Beale–Kato–Majda criterion: $\int_0^T \|\omega\|_{L^\infty} dt < \infty \Rightarrow$ гладкость.

3. $\|u\|_{L^3}$ контролирует $\|\omega\|_{L^\infty}$ через вихревую уравнения и bootstrap argument.

Задача 5: P vs NP → 3-SAT

Утверждение: $P = NP \Rightarrow$ существует полиномиальный алгоритм для 3-SAT.

Доказательство:

1. 3-SAT — NP-полная задача (Кук, 1971).

2. Если $P = NP$: каждая задача из NP решается за полиномиальное время.

3. 3-SAT ∈ NP → 3-SAT ∈ P → существует алгоритм за $O(n^k)$.

Обратное: Если $P \neq NP$, никакой полиномиальный алгоритм для 3-SAT не существует. Это эквивалентно existence of super-polynomial circuit lower bounds.

Задача 6: Янг–Миллс — конфайнмент на решётке

Утверждение: На $\mathbb{Z}^4$ для $SU(2)$: $W(C) \sim e^{-\sigma \cdot \text{Area}(C)}$ при больших контурах $C$ ($\sigma > 0$).

Подход (Куммер, 1982):

1. Калибровочная теория на решётке — конечномерная, математически строгая.

2. Wilson loop: $W(C) = \frac{1}{N}\mathrm{Tr}\,\mathcal{P}\exp\left(ig\oint_C A_\mu dx^\mu\right)$.

3. Для $SU(2)$ на решётке: доказано, что $W(C) \leq C_1 e^{-\sigma \cdot \text{Area}}$ (dual lattice methods).

4. Общий случай (континуум, $SU(N)$, 4D) остаётся открытым.

2. Междисциплинарные связи

Математика ↔ Физика

Навье–Стокс ↔ Теория поля: Уравнения Навье–Стокса — классические пределы квантовой хромодинамики (QCD). Массовый промежуток Янга–Миллса → конфайнмент → аналог вязкого трения.

Риман ↔ Квантовая физика: Гипотеза Римана эквивалентна statement о спектре гамильтониана Random Matrix (GUE distribution). Нули $\zeta(s)$ ведут себя как собственные значения матриц из GUE.

Математика ↔ Информатика

P vs NP ↔ Гипотеза Римана: Нет прямой связи, но обе связаны с вычислительной сложностью. Алгоритмы для $\zeta(s)$ (Riemann-Siegel formula) — $O(t^{1/2+\varepsilon})$, что рядом с полиномиальной границей.

BSD ↔ Криптография: Эллиптические кривые — основа ECC (elliptic curve cryptography). BSD определяет, насколько «предсказуема» структура кривых.

Физика ↔ Химия ↔ Биология

Навье–Стокс ↔ Биомеханика: Течение крови (реологические свойства), диффузия кислорода в тканях — всё описывается модифицированными уравнениями Навье–Стокса.

Квантовая химия ↔ Молекулярная биология: Шрёдингер →Electronic structure → молекулярные орбитали → ферментативные реакции → метаболизм.

Термодинамика ↔ Экология: Второе начало термодинамики → энтропия экосистем → трофическая эффективность (закон Линдемана 10%).

Астрономия ↔ Все науки

Космология ↔ Математика: Уравнения Фридмана ( cosmological expansion) — системы ODE, связанные с термодинамикой и гравитацией. Тёмная энергия ↔ космологическая постоянная $\Lambda$.

Стелларный нуклеосинтез ↔ Химия: Все элементы тяжелее гелия созданы в звёздах и сверхновых. «Мы сделаны из звёздной пыли» — буквально: Fe в крови, C в ДНК, O в клетках.

4. Методологические выводы

Из 101 задачи:

  • 6 задач тысячелетия — ни одна не решена полностью (2 частично доказаны: BSD для рангов 0–1, Навье–Стокс в 2D)
  • 95 элементарных задач — решены. Покрывают основы 7 наук.
  • Ключевой вывод: математика, физика, химия, биология, информатика, астрономия и логика образуют единую сеть связей, а не изолированные дисциплины.

Оптимизация для LLM

Кэширование: Формулы задач тысячелетия — хэшировать и переиспользовать в других контекстах.

Экстраполяция: Знание 95 элементарных решений позволяет решать составные задачи через composition.

Связи: Карта междисциплинарных связей (§2) — ключ к решению задач, требующих знаний из нескольких областей.
