Theorem 1: Master Theorem: T(n) = aT(n/b) + O(n^d) solves to: d > log_b(a) => Theta(n^d), d = log_b(a) => Theta(n^d log n), d < log_b(a) => Theta(n^{log_b(a)})

Statement: If T(n) = aT(n/b) + Theta(n^d) with a >= 1, b > 1, then: - If d > log_b(a): T(n) = Theta(n^d) - If d = log_b(a): T(n) = Theta(n^d * log n) [balanced case] - If d < log_b(a): T(n) = Theta(n^{log_b(a)})

Hypotheses: Given assumptions in time

Conclusion: The stated property holds

Definitions: fundamental definitions in time

Proof sketch:

Step 1: Draw recursion tree: level i has a^i subproblems each of size n/b^i.

Step 2: Work at level i: a^i * (n/b^i)^d = n^d * (a/b^d)^i.

Step 3: Sum over log_b(n) levels: sum_{i=0}^{log_b(n)} n^d * (a/b^d)^i.

Step 4: Case 1 (d > log_b(a)): a/b^d < 1, geometric sum converges, root dominates => Theta(n^d).

Step 5: Case 2 (d = log_b(a)): a/b^d = 1, each level has equal work n^d, total => Theta(n^d * log n).

Step 6: Case 3 (d < log_b(a)): a/b^d > 1, leaf dominates => Theta(n^{log_b(a)}).
