Theorem 1: Pigeonhole: n+1 objects in n boxes => some box has >= 2

Statement: Pigeonhole: n+1 objects in n boxes => some box has >= 2

Hypotheses: n+1 objects, n boxes

Conclusion: some box has at least 2 objects

Definitions: pigeonhole, counting

Proof sketch:

Step 1: Assume each box has at most 1 object

Step 2: Then at most n objects total

Step 3: But we have n+1 > n objects

Step 4: Contradiction
